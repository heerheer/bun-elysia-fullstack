# bun-elysia-fullstack

A minimal Bun full-stack starter with:

- Frontend in `src/` (React + shadcn-style UI + Zustand + React Router + TanStack Query)
- Backend in `server/` (Elysia + CORS + Static + OpenAPI)
- End-to-end type-safe API calls via `@elysia/eden`
- Tailwind CSS v4.2 configured with Bun's Tailwind plugin in `bunfig.toml`

## Scripts

- `npm run typecheck` – TypeScript validation
- `npm run dev:server` – run Elysia backend via Bun
- `npm run dev:frontend` – run frontend with Bun
